## 安裝與版本
- 保留原本 `bio-classification-v2` 儲存庫；不要覆蓋分類 1.0。
- 在 GitHub 把 ZIP 解壓後的全部檔案和 `icons/` 資料夾上傳至根目錄；Settings → Pages 選 `main` / `/(root)`。
- 上傳後先連網重新整理一次，確認載入 2.2.3，再測安裝與飛航模式。
- PWA 可獨立加到主畫面；若要入口網離線打包，仍需將此單元資源一起部署到入口網的控制範圍內。

## 教學內容注意
- 「產出遺傳變異的後代」和「有性生殖」不是同義詞。無性生殖也可能因突變產生遺傳變異，因此本版以「是否有機會產生具有遺傳差異的後代」處理，並非判斷是否進行有性生殖。此欄是否適合直接用於國中複習，仍建議教師實機驗收後再定案。
- 第二頁不提供 RNA / 不適用 選項；病毒沒有一般細胞構造，暫不納入第二頁可直接訂正的出題池，但仍保留在第一頁。
