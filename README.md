# 生物分類 2.2｜原版介面還原版

這次以你原本上傳的 `index(5).html`、`stage1.html`～`stage4.html` 為外觀基準，而不是沿用 2.1 改版的全新視覺樣式。四個分頁同一個 GitHub Pages 儲存庫、同一個獨立 PWA。

## 四頁改動

1. **五界整體複習**：保留原版五界表格、逐欄選擇與蓋章操作；新增粒線體、套用 2.1 共用資料庫；所有欄都在同一畫面，不採左右捲動。
2. **小老師閱卷**：保留原版紙張與紅筆感；學生現在直接將不正確的內容改成正確資料，批改時依整張考卷最後答案判斷；保留原卷、換題和儲存紀錄。
3. **偵探解謎**：保留原版黑底雙欄、五界卡片與三位角色；十個案件圖片已壓縮並**直接嵌入 stage3.html**，不需要 assets/ 圖片資料夾，避免 GitHub 上傳遺漏路徑；Q8 一律使用同一張海綿圖片。為了不捲動，線索以 1、2、3 按鈕切換；解謎與進度功能保留。
4. **二分叉檢索表**：恢復原版「膠囊按鈕、藍色分類標籤、紅色生物卡、O／X 分叉」風格；新增五界混合／純植物／純動物同款按鈕；保留種類／真實生物名稱、正向／逆向、4／6／最多8種、撤銷與多重正解。

## 頁面全版鎖定

所有分頁無頁面捲動、無水平捲動、無內部卷軸。檢索樹自動縮放適應可用畫布。直向會出現可關閉的橫向建議，但不強制旋轉。

## 部署到 GitHub Pages

1. 建議先備份／標記現有 2.1，**不要覆蓋原版 1.0 儲存庫**。
2. 將這份 ZIP 解壓，選取全部根目錄檔案與 `icons` 資料夾，上傳到同一個分類 2.0 測試 GitHub 儲存庫根目錄（不要直接上傳 ZIP）。
3. GitHub Settings → Pages → Deploy from a branch → main → /(root)。
4. 網頁更新後，如仍看到舊畫面，重新整理並關閉重開已安裝 App；必要時在 Safari 清除舊版網站資料再重新加入主畫面。
5. 等 iPad Safari 實機測試、離線重啟都驗收通過，再替換入口網對分類單元的連結。
