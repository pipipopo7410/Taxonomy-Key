# 生物分類特訓 2.1｜四頁整合測試版

這份 ZIP 是**一個 GitHub Pages 儲存庫**、**一個可安裝的生物分類 PWA**，內含四種學習活動。分類 1.0 不需要更動；2.0.2 的第一頁內容也完整保留。

## 四個活動

1. **整體複習** `stage1.html`：逐欄聚焦、逐格蓋章，保留粒線體與之前確認的國中五界特徵。表頭、生物名稱欄位與本機作答紀錄保留。
2. **小老師訂正** `stage2.html`：在同學填好的生物特徵筆記中直接選取正確內容，按「批改完成」後依所有格子的最終內容判斷。提供「還原原卷」、「換下一張」及本機進度保存。
3. **偵探解謎** `stage3.html`：保留十個案件與原始人物／圖片，案件線索逐步揭露。可以點按或拖曳排除嫌疑類群，移除「必須先排除才能看下一線索」的限制；保留案件進度，選錯不強制重來。第八案**刻意**維持揭曉前後同一張海綿照片。
4. **二分叉檢索表** `stage4.html`：五界混合／純植物／純動物 × 種類／真實生物名稱 × 正向／逆向 × 4／6／最多 8 種。允許等價的分類特徵、避免同一代表類群重複出題、新增「撤銷上一步」與本機進度保存。

## 上傳到 GitHub（一次上傳）

1. **解壓縮 ZIP**，不要把 ZIP 本身上傳後期待 GitHub 自動解壓。
2. 打開原本用來測試分類 2.0 的 GitHub 儲存庫（建議 `bio-classification-v2`），如尚未建立則先建立一個公開儲存庫。
3. 將解壓後的**所有檔案，以及 `assets/`、`icons/` 兩個資料夾**一起上傳到儲存庫根目錄，取代同名檔案。
4. 若尚未開啟 Pages：Settings → Pages → Deploy from a branch → main → /(root)。
5. 開啟部署網址，以 Safari 在 iPad 檢查四個活動，最後才「加入主畫面」。

**注意：** 此 ZIP 的根目錄就是網站根目錄，不能把全部檔案塞進多一層資料夾，否則相對路徑會失效。

## 主要檔案

- `index.html`：四頁共用入口
- `stage1.html`～`stage4.html`：四個活動
- `data.js`：共用生物科學特徵與檢索表題庫
- `assets/`：十案圖片與三位偵探人物（WebP）
- `manifest.webmanifest`、`icons/`：可加入主畫面的 PWA 設定與圖示
- `sw.js`：核心檔案與圖片離線快取
- `unit.json`：供未來「剛剛數位小教室」整包離線整合
- `明日iPad驗收清單.md`：實機測試步驟

## 科學範圍提醒

- 本活動採國中五界典型特徵模型，不將類群典型特徵視為所有實例的絕對定律。
- 黴菌與香菇因現有分類特徵無法區分，程式不會在同一題同時抽取。
- 「真實生物名稱」指常用名稱，不保證是唯一的種級學名。
- 五界生態功能、細菌有性生殖、藻類單／多細胞、病毒遺傳物質等，依先前共同確認的教學取捨設定；若要做正式會考題，請先核對學校採用的教材版本。

## 離線／入口網站

此站本身可在 iPad Safari 加入主畫面；首次要連線載入全部資源。**這份 ZIP 尚未修改總入口網站。** 未來若要「從總入口安裝後四頁全離線可用」，需將分類單元資源部署到總入口同源路徑，並一併修改總入口的快取規則；單純貼上分類網站的連結不能保證整包離線。

本次已完成 Chromium 內嵌頁面互動模擬，**尚未以 GitHub Pages 正式網址完成 iPad Safari 實機與飛航模式重開驗證**。完成前請維持「測試版」，不要取代 1.0。
